## Fonctionnalités

### ✨ Design Moderne
- Interface utilisateur moderne et élégante
- Palette de couleurs cohérente (turquoise/teal)

## Installation et Utilisation

1. **Cloner ou télécharger** les fichiers dans un dossier
2. **Ouvrir** `index.html` dans un navigateur web
3. **Naviguer** à travers les différentes sections

### Lancement avec serveur local (recommandé)
```bash
# Avec Python 3
python -m http.server 8000

# Avec Node.js (si installé)
npx serve .

# Avec PHP
php -S localhost:8000
```

Puis ouvrir : `http://localhost:8000`

## Personnalisation

### Couleurs
Les couleurs principales sont définies dans les variables CSS :
```css
:root {
    --primary-color: #1dd1a1;
    --secondary-color: #00d2d3;
    --dark-color: #2c2c54;
    --light-color: #f8f9fa;
}
```
